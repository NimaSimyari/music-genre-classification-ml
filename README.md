# 🎵 Music Genre Classification using Machine Learning

## 📌 Project Overview
This project focuses on building a **Music Genre Classification system** using Machine Learning techniques. The goal is to analyze audio features and predict the genre of a given music track.

The project includes:
- Exploratory Data Analysis (EDA)
- Data preprocessing and feature engineering
- Model training and hyperparameter tuning
- Evaluation of multiple machine learning models
- Final model selection and performance analysis

---

## 📂 Project Structure
The objective is not only to achieve strong predictive performance, but also to provide a reproducible and systematic experimental pipeline for music genre classification.

## ♻️ Reproducibility

The repository contains the main notebooks, processed datasets, model outputs, and supporting files required to reproduce the machine learning experiments.

The analysis is organized into separate stages for data exploration, preprocessing, model development, hyperparameter tuning, and final evaluation to make the experimental process easier to inspect and reproduce.
